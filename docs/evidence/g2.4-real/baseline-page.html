Principles

Three habits this tool is built around

01

No toolbars while drafting

In Draft the screen is only your words. Menus, colour and notes wait behind a folded edge until you say: revise.

02

Cuts are reversible folds

Nothing is deleted permanently. Every cut is stored as a fold you can reopen, so scenes leave easily and return without blame.

03

Formatting waits until export

The manuscript keeps only plain structure — heading, aside, note. A clean export pass adds type and layout at the very end, never during.

Questions

Asked & answered

Can I actually use Paperlane today?

No. Paperlane is a fictional product / concept demo created for a design exercise. There is no app, no account system and no backend behind this page — every word here is illustrative only.

What happens if I fill in the start form?

Nothing is sent. The demo controls above are disabled on purpose, because there is no server to receive the data. No email, name or draft leaves your browser — this page collects nothing and talks to no network.
