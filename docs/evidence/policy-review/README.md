# Policy review gate evidence

Recorded 2026-10-15 using the pinned local Harness and fixed responses only. Paid requests: zero. These files are immutable evidence of this gate; future runs belong in new records.

- `verification.json`: exact choice/session lineage, distinct generation/evaluation/daily totals, complete native task, evaluation-child cleanup and released host ports.
- `browser-result.json`: real Harness sidebar confirmation, cancellation, adoption, restoration and reload checks.
- `native-session.json`: the old bound session's native permission/model initialization, request headers, tool calls/results and completed turn. The native permission preset is not an OS isolation claim.
- `sidebar.png`, `sidebar-narrow.png`: inspected 1440px/760px screenshots. RSI remains readable; the host's existing center pane compresses at the narrow width.
- `check.txt`: the final complete typecheck/test/build log.
- `preservation.json`: content-hash comparison against all 51 files already dirty before this turn; 42 unchanged, 9 intentionally extended, none missing.

Full controller databases, failed-run captures and authenticated host logs remain under the recorded `.cache/policy-review-*` directories. They were retained rather than reset. All recorded services are stopped. Scripted outputs establish protocol, permission/accounting boundaries and recovery behavior, not model quality or performance gains.
